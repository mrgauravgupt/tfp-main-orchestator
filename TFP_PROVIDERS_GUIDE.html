🗄️ Database

🐘
PostgreSQL + Prisma ORM
Required Primary Database
Purpose: The single source of truth for all application data — users, profiles, opportunities, events, contests, moderation cases, messages, notifications, referrals, the event outbox for background jobs, and collage job state. Prisma ORM handles migrations, the type-safe query layer, and DB instrumentation via OpenTelemetry. PostgreSQL's FOR UPDATE SKIP LOCKED is used for queue-safe worker polling without a separate queue broker.

Content Safety

🛡️ Image Moderation Providers

🏠
TFP Image Moderation Service (AIP) — Self-Hosted
Primary / Production Self-Hosted AI Inference
Purpose: The primary moderation backend. A custom Python FastAPI microservice running YOLOv8, NudeNet 3.4, CLIP, and NLLB-200 models locally. The main API calls it over OCI-host-local HTTP to score images for adult content and violence. It listens only on 127.0.0.1:7001. It also doubles as the translation backend when ACTIVE_TRANSLATION_PROVIDER=remote-http.
Runtime
Python 3.11 + FastAPI + PyTorch + ONNX
UAT URL
http://127.0.0.1:7001 (OCI host only)
Models
YOLOv8, NudeNet 3.4, CLIP, NLLB-200
Repo
tfp-image-moderation-service/
ACTIVE_MODERATION_PROVIDERrequiredSet to "remote-http"
MODERATION_REMOTE_URLrequiredOCI UAT: http://127.0.0.1:7001
MODERATION_REMOTE_AUTH_TOKENrequiredMatches AIP__SECURITY__INTERNAL_API_KEY on the service
AIP__SECURITY__INTERNAL_API_KEYservice-sideSet in tfp-image-moderation-service/.env
No external sign-up needed. This is a self-hosted service in your own repo. Deploy on a VPS with ≥4 GB RAM for YOLO + NudeNet models.
