Deep research: what “modern” means now

The strongest current systems add dimension through layers, variable rendering and state-aware motion—not gratuitous 3D treatment on every control.

official sources · 2026 review
Phosphor Duotone ↗

Six coordinated weights—including duotone and fill—and a very broad catalog. Best fit for TFP’s expressive cross-platform base because one concept can move from quiet regular to premium duotone without changing family.

Best static foundation
SF Symbols effects ↗

Draw on/off, magic replace, bounce, wiggle, breathe, rotate, pulse and variable color show the current benchmark: animation communicates action, state or progress and remains layered.

Best motion grammar
Material 3 Expressive ↗

Google’s current direction combines vibrant color, contrasting shapes, adaptive components and tokenized motion physics. Useful inspiration for TFP containers and active states, not a reason to adopt Material wholesale.

Best expressive UI cues
Material Symbols ↗

Variable fill, weight, grade and optical-size axes make one symbol react smoothly to hierarchy and selection. A strong alternative where variable-font delivery is preferred.

Best variable system
Lordicon ↗

Large ready-made animated library with web, React and Flutter integrations. Fast for prototypes and campaign surfaces, but licensing, visual consistency and runtime weight need review before product-wide adoption.

Best ready-made animation
Rive state machines ↗

Interactive vector assets can respond to real state and settle when inactive. Best for onboarding, empty states, upload success and hero moments—not ordinary 20px toolbar controls.

Best living illustration
Streamline Neon ↗

Modern two-color icons across Core, Flex, Sharp and Plump families. Plump Neon is the closest external reference for TFP Proposal 2: friendly curves, quick recognition and strong dark-mode hierarchy.

Best Proposal 2 reference
Hugeicons Duotone ↗

Recent duotone, bulk and solid styles plus typed dynamic loading. Especially strong coverage for communications, image-camera, maps, search, git and status variants.

Best catalog alternative
Icons8 3D Fluency ↗

Glossy and minimalist 3D objects work well for onboarding, dashboards and marketing surfaces. Use as Proposal 3 inspiration or licensed illustration assets—not as tiny toolbar icons.

Best Proposal 3 reference
✅ Use expressive Level 2

Primary navigation active state, winner reveal, first upload, empty states, onboarding, creation hub, achievements and meaningful success moments.

⚠️ Use restrained motion

Like/save/vote confirmation, filter open/close, upload progress, notification status and content transitions. Trigger once and preserve a static resting state.

⛔ Keep Proposal 2 compact

Close, back, search, overflow, form metadata, destructive actions, dense admin tables and repeated list rows. Clarity and scan speed win here.

Motion accessibility: every effect in this report stops under prefers-reduced-motion: reduce. Production animation should be opt-in from a static baseline, avoid perpetual motion, and never be the only indication of state.

Proposed icon grammar

Small enough to govern the system without overengineering it.

SSOT
24 × 24 grid

Functional glyphs share the same coordinate system, optical center, round caps and joins.

1.75–2px stroke

Use 1.75px at 20–24px, 2px at 16–18px; filled icons only for selected/favorite state.

16 / 20 / 24 sizes

16 inline, 20 controls, 24 navigation. 32–48 only for empty states and illustration moments.

44px interaction

The glyph may be 18–20px; every standalone pointer/touch action gets a minimum 44px target.

Color follows state

Default inherits currentColor. Gold is emphasis, magenta active/brand, red danger—never random per icon.

Labels own meaning

Decorative icons are hidden. Icon-only controls require an accessible label and visible focus.

Verb vs noun

Upload/add/edit for actions; image/file/calendar for content and metadata. Do not interchange them.

Three governed tiers

Phosphor-compatible functional icons, a tiny TFP brand set, and rare Rive/Lordicon-style living illustrations. No ad-hoc fourth family.

Safe implementation path

Recommended follow-up; no application source was changed by this audit.

4 phases

Contract

Define semantic names, sizes, stroke, accessibility defaults, and exceptions. Export one shared IconName union and usage map.

Converge web

Replace the 62 raw inline instances and text symbols with central components, starting with form uploads, closes, and contest engagement.

Align native

Map mobile’s existing Lucide imports to the same semantic names. Keep native rendering local; share vocabulary, not framework code.

Guard

Add a narrow audit that flags raw SVG in product UI, emoji in UI catalogs, unsupported icon names, and icon-only controls without labels.

Preserve: logos, favicons, app-launch assets, placeholders, OG/email raster branding, CSS noise textures, and genuinely illustrative artwork are not functional icons and should not be forced into the icon registry.
