# Antigravity workspace configuration

- `rules/` contains persistent behavioural constraints. Configure investigation and task-safety rules as **Always On** in Antigravity; configure broad-audit quality as **Model Decision**.
- `workflows/` contains repeatable slash-command procedures. Confirm workflow discovery after reopening the project.
- `skills/` contains focused, progressively loaded procedures. Do not make every skill a global rule.

The root `GEMINI.md` holds only stable workspace context. `AGENTS.md`, `RULES.md`, and repository-local instructions remain authoritative for detailed engineering and operational constraints.
